## Selected projects

### Formly
Build and publish conversational forms, embed them on another website, and review responses stored in PostgreSQL. Published snapshots keep live forms stable while drafts change.<br>
<sub>TypeScript · Next.js · React · PostgreSQL</sub><br>
[Code](https://github.com/almuzahidseyam/formly-chat-forms) &nbsp; / &nbsp; [Try the demo](https://formly-chat-forms.vercel.app/demo)

### BD_TSP
Compare exact Held–Karp tours for a 15-hub distance matrix with heuristic routes across 64 districts in Bangladesh. Combines a C++ solver, directed road distances and interactive maps.<br>
<sub>C++17 · Python · OSRM · Folium</sub><br>
[Code](https://github.com/almuzahidseyam/BD_TSP) &nbsp; / &nbsp; [Methods & examples](https://github.com/almuzahidseyam/BD_TSP#choose-a-demonstration)

### LumaWeave
Add gesture-controlled visual effects to your Google Meet camera feed. Bundled MediaPipe models track hands locally, and a frame-driven rendering pipeline returns the processed video to Meet.<br>
<sub>JavaScript · MediaPipe · Canvas · Chrome Extensions</sub><br>
[Code](https://github.com/almuzahidseyam/lumaweave) &nbsp; / &nbsp; [Preview](https://github.com/almuzahidseyam/lumaweave/blob/main/docs/preview.png) &nbsp; / &nbsp; [Download](https://github.com/almuzahidseyam/lumaweave/releases/latest)
